# 场景包：党课与领导讲话（G2 高政治敏感体裁）v10.0

> 门控：体裁为 G2（党课、领导讲话稿、干部大会讲稿），且讲者面向下属单位或基层听众。判依据上接 [`../stance-and-register.md`](../stance-and-register.md) §2.1 听众反应预演。
>
> 本文件从 2026-07 一篇央企党课的实战中蒸馏：领导对初稿的审改、八路独立审读约 70 条意见的逐条甄别、以及把修改变提炼成写作标准的全过程。已脱敏，不携带任何具体单位的经营数据。

## 1. 矩阵行引用

对应站位矩阵行：**领导对下属**（部署工作、提出要求、肯定成绩、指出不足；绝对不能让下属听了会多想）。党课在此行之上加一层：讲者代表党委作组织传达，不是个人布道。

## 2. 一条主线

把稿子从“我”本位的个人布道（讲者当亲历者、表功者、施恩者、训导者，又表功、又敲打、又打气、又抒情）校正为“公”本位的组织传达（讲者代表党委平实讲理，和大家一起把差距摆进去）。

**为什么这一层最容易翻车**：讲者层级越高、越是面对下属单位，台下的人越会放大解读每一句话。动笔之前先过一遍那句话：“这句话，台下的人听了会怎么想、会不会多想？”

## 3. 站位铁律（四组）

### 3.1 站位：讲者与受众的关系

- **功劳归台下**。涉及下属单位的具体业绩，只客观陈述（某单位、某数据），绝不用“我见证”“我和某某一道”“这是我们干出来的”去认领或分享。
- **不以某单位一员自居抒情表功**。“我们某某人干出来的”“这一代某某人”一律不写：上级讲者不降格并入某一子公司（与单位叫什么名无关）。
- **可讲问题、不摆训人架子**。尖锐的真问题可以讲；但“把丑话说在前头”“红红脸出出汗”“主动对号入座”“爱之深责之切”这类整风式、长辈式框架要清。
- **不喂定心丸、不施恩打气**。“我给大家吃颗定心丸”“你们别慌我来兜底”“你们扛得不易”这类预设听众心虚、由上位者情绪施予的表达一律删。
- **开篇结语走公务开合**。开篇从“代表党委传达部署”起，不以“我带你们去看”“专门派我来讲”这类个人经历开场；结语落在共同任务，不用悲情榜样对下属道德加压，不把党课私人化为“我最大的心愿”。

### 3.2 语气与语体

- **删元叙述脚手架**。讲者自曝写法的句子（“我不想一上来就念文件”“我给大家摆一组数字”“讲党课要用数据服人”“我逐条过一过”）一律删：可信度来自内容，不来自对技法的解说。
- **最高级与强度词降档、留余地**。最透最深改很深很透，真理力量改重要论述，巨大威力改巨大力量。公文忌“满”、忌把话说死。
- **国家叙事不硬拽单位收尾**。每讲一段国家大势就贴一句“我们如何”表忠心，成段删；宏大论述保持完整庄重，单位落点集中到专门段落讲。
- **锋利用陈述判断式，不用第一人称煽情**。
- **口语比喻分场景**。服务说理的留（温水煮青蛙、算一笔账、一亩三分地）；服务施压、把听众置于受审地位的删。

### 3.3 内容取舍与分寸

- **批评与安慰不同篇**。同一篇里刚批评过“守摊子、舒适区”，就绝不能再发“别怕，你们的老本行是抢不走的宝贝”式安慰：逻辑自拆台，等于给躺平发通行证。
- **不自我贴金、不越位借光**。不把国家或兄弟单位的成就硬扣到本单位头上；举例要贴本单位主业，不拿不相干的大国重器给自己脸上贴金。
- **方向可讲满，数字不说死**。远期、量化、技术性判断不由讲话人背书；方向性判断可留，可被证伪的硬承诺不留。
- **例子须服务论点、且不与本篇主张打架**。讲长期主义留接续奋斗式的例子；讲科学决策就别用拼命蛮干式的榜样。宁缺勿凑，跑题即删。
- **留批评、收锋芒**。批评的实质全保留，只在最尖锐、最像“点名定罪”的那一处留一分余地。这不是和稀泥。

### 3.4 语境、称谓与事实

- **企业语，不用官场语**。受众是企业经营干部，用“企业发展好、效率高、效益好”，不用“为官一任”“题中应有之义”这类施政话语。
- **称谓先定口径、全篇统一**。动笔前先定一次称谓（含内部与对外口径可能不同、是否已更名未公布），全篇一致，避免多种写法并存。
- **引文一字不改**。宗旨使命处可强化为国奉献的基调；给领导原话“加料”只放在讲者自己的小标题或提法，直接引述保留原文，防误引领导。
- **战略专名零歧义**。战略、工程名、重要论述等专名全篇一字不差，重点复核同段或前后是否并存两种写法。
- **改稿必回归通读校对**。软化、替换、删并最易引入新错字与断句，每改一处，通读改动点上下两句。

## 4. 高风险“听众多想”清单（正反例）

| 反例（台下会多想） | 正例 | 听众的解读 |
|---|---|---|
| 我和某同志一道去看……这就是我们某某人干出来的 | 某单位某项目投产、某数据（客观陈述，不认领） | 这是来抢我们的功？ |
| 我先把丑话说在前头，不是来唱赞歌的 | （删，直接进入内容） | 今天是不是要整人？ |
| 给大家吃一颗定心丸，你们的老本行不会被淘汰 | （删；价值让政策与事实去说，方向可讲、定心丸不发） | 领导是不是觉得我们慌了？ |
| 为官一任，让老百姓看得见摸得着得实惠 | 既要当前企业发展好、效率高、效益好 | 这是把我们当地方官衙门？ |
| 真理力量 / 巨大威力 / 讲得最透最深 | 重要论述 / 巨大力量 / 讲得很深很透 | 话说满了，出事谁担？ |
| 用拼命蛮干式榜样讲科学决策 | 换接续奋斗式例子（服务本篇论点） | 到底是让我科学还是让我拼命？ |

## 5. 稿件血统溯源闸门（集成审读前必过）

集成审读或润色意见前，先逐条溯源到稿件血统：这句话出自领导审定稿，还是我方增补？

- **命中领导审定文字的意见一律不采**，包括“软化尖锐批评”“删口语比喻”这类看似专业的建议。实证：本案八路独立审读共提约 70 条意见，其中高共识的“软化”建议 23 处，经逐句比对全部落在领导定稿保留的尖锐批评上，最终一处未回改。
- 意见只在我方增补、领导未改处落实。
- 审读者（人或 AI）看不到稿件血统，意见再专业也不能越过领导定稿；溯源是集成前的硬闸门，不是可选项。

## 6. 交付前自检清单

- [ ] 通篇没有讲者认领下属功劳、没有“我们某某人”式自居表功。
- [ ] 没有“把丑话说在前头 / 红红脸出出汗 / 对号入座”等训导施压句。
- [ ] 没有定心丸、没有施恩打气、没有自我贴金与越位借光。
- [ ] 没有元叙述脚手架；最高级与强度词已降档留余地。
- [ ] 批评与安慰不同篇；例子都服务论点、不与本篇主张打架。
- [ ] 用企业语非官场语；称谓全篇统一；专名零歧义；引文一字不改。
- [ ] 逐句自问过“这话台下会怎么想、会不会多想”。
- [ ] 领导已改、已删之处一处未还原；充实只发生在领导未改处。
- [ ] 外部审读意见已逐条溯源，命中领导审定文字的一律未采。

## 7. 已知假阳清单

| 假阳 | 为什么不报 |
|---|---|
| 必备政治表态、指导思想段 | 体裁必备成分，与听众预演无关（constitution §0.5 豁免） |
| “一是……二是……三是……”列举 | 党政标准句式，不是布道腔 |
| 客观陈述下属单位成绩（不带认领主语） | 功劳归台下恰恰要求客观陈述，陈述本身合法 |
| 讲者自述调研经历作为论据 | 属于材料，不属于表功；是否保留由立意焦点判 |
| 对 G6 / G7 稿件跑本检查 | 听众预演只门控 G2（stance-and-register §2.0） |

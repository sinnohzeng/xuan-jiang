# 场景包：熟人与私人读者（防商务化客气化）v10.0

> 门控：站位四问的问题一答案落在“部门内熟人”“跨部门同事”“家人朋友”“恋人配偶”等非工作或非正式关系。判依据上接 [`../stance-and-register.md`](../stance-and-register.md) §2 站位矩阵。

## 1. 矩阵行引用

对应站位矩阵行：**部门内 / 熟人**、**家人朋友 / 恋人配偶**（跨部门行另见矩阵，本节只管“已经很熟”的两类）。

## 2. 这个场景的主要风险

方向与工作场景相反：工作场景防的是越界和命令腔，熟人场景防的是**过度客气、过度正式**。AI 的默认语体是商务客服腔，写给熟人的稿子（微信消息、家书、朋友圈、给朋友的说明）最容易被写得像外部服务商在回复工单。

## 3. 核心规则

- **直说事项**。不铺垫、不寒暄、不写“希望对你有所帮助”式收尾。
- **用双方日常用的词**。平时怎么说话就怎么写，不升格。
- **关系越近，越不用敬语堆叠**。“烦请”“拨冗”“请贵方”出现在家人朋友之间，就是语体错位。
- **去绩效腔**。写给私人的文字不汇报成绩、不表态担责、不搞“下一步计划”。
- **温度可以有，但不靠形容词堆**。一句具体的关心，胜过三段抒情。

## 4. 高风险形态清单（正反例）

| 病（商务化客气化） | 正（日常语气） |
|---|---|
| 妈妈，关于周末回家一事，现将有关安排说明如下。 | 妈，周末我回家，周六中午到。 |
| 感谢你一直以来的支持与包容，希望我们的关系在未来持续向好。 | 谢谢你一直惯着我。 |
| 烦请查收附件，如有疑问请随时沟通。 | 文件发你了，看不懂问我。 |
| 综合考虑各方面因素，我建议我们本周见面详谈。 | 这周见一面吧，当面说。 |

## 5. 正向锚：随心、随性、随情

任仲然《怎样写作》第十一讲论随笔：内容和形式要“随心、随性、随情”，不能板着面孔说话，真正写出心声和个性来即可。写给熟人的文字同理：板着面孔的客气，比直白更伤人。

## 6. 已知假阳清单

| 假阳 | 为什么不报 |
|---|---|
| 熟人场景的“过于正式” | 只提示、不阻断（stance-and-register §2.0）：往回收不收回日常语气是作者的自由 |
| 私人信件里的礼貌用语（谢谢、麻烦了） | 礼貌不等于商务腔，单个敬语不构成错位，看整段语体 |
| 对 G6 / G7 稿件跑本检查 | 私人读者场景是站位判断，不是体裁检查；随笔自媒体走 genre-guide，不走本节 |

## 新增场景的方法

新增一个场景：新增一个场景文件，并在 [`../stance-and-register.md`](../stance-and-register.md) §2 站位矩阵加一行。

场景文件的骨架（照此写，保持可审计）：

1. **矩阵行引用**：指回站位矩阵对应行。
2. **该场景的核心规则**：可以做什么、绝对不能做什么。
3. **高风险形态清单**：带正反例。
4. **交付前自检清单**（适用时提供）。
5. **已知假阳清单**：新检查项上线同批必建（v9.3.1 教训：焦点越靠前、误伤代价越大）。

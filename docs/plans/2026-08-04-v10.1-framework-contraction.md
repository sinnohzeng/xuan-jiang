# v10.1.0 框架收缩 spec（收缩机械化 + 吸收 human-writing 理念）

> 日期：2026-08-04。依据：`docs/research/2026-08-04-human-writing-absorption.md`。
> 一句话：scan 脚本只执行无歧义硬禁，语境判断交 reviewer；四源漂移收敛为单一 SSOT + 机械校验；理念层吸收 human-writing（MIT）。

## 1. 目标

1. 收缩机械层：把精确率 ~18% 的硬 FAIL 集合削减为“无歧义集”，误伤源（公文合法词、国标合法标点、教学合法结构）降为软 WARN。
2. 修复四源漂移：黑词清单收敛为 anchors §1.1 唯一 SSOT，其余消费方改指针，新增机械一致性校验。
3. 吸收外部理念：七遍改稿与材料门槛进入判据层（注明 human-writing MIT 出处）。
4. 硬红线只减不增：本轮不新增任何硬 FAIL 规则。

## 2. 非目标（含不吸收清单）

- **不做形状检测族脚本**：比喻聚类、段首重复、短句排队、段落过度单一等一律不加——形状判断无字面唯一解，机械实现必产生新一批假阳；形状判断交 reviewer（与本轮收缩主题一致，理由全文见 research §四）。
- 不合并 references 判据文件；不动 `constitution.md` / `stance-and-register.md` 两大重资产。
- 不搬 human-writing 的绝对禁冒号/破折号一刀切、材料门槛硬闸、未过体裁门控的 30 词禁词表（理由见 research §四）。
- 不重构离线 eval 打分链；不动 reviewer 的输出格式契约。

## 4. 需求清单

### REQ-1 scan 脚本机械层收缩（唯一定义文件：`scripts/scan-ai-taste.sh`）

降级为软 WARN（进 WARNINGS、exit 2，不再 exit 1）：
- CN_HARD 移除公文合法词 8 个：切实推动 / 提质增效 / 深度融合 / 打造 / 助力 / 多维度 / 体系化 / 重塑；保留 7 词（赋能 / 闭环 / 抓手 / 链路 / 拉通 / 话语建构 / 跨界融合，以文件实际为准）。降级词转入软信号输出，措辞「供 reviewer 语境判断：本义准确保留，抬价堆砌改写」。
- 破折号（原阈值=0、仅法律语境豁免）→ 软 WARN；GB/T 15834 合法标点，文体取舍交 reviewer，法律语境提示并入 WARN 措辞。
- 首先/其次/最后三段式（原阈值=0）→ 软 WARN；教学/讲稿语境合法。
- 已经/核心/这一 密度阈值 → 保留计数与 WARN，措辞标注「密度提示，不作改稿目标」（防 Goodhart，SKILL.md L157 铁律已有前科）。

删除：
- `fix_word` 逐词替换建议表及其调用（references/failure-cases.md 案例 1 已证伪机械近义词替换）。
- GENRE=auto 占位分支（自注“暂等同 base”且无实现计划；`--genre` 参数本身保留）。

保留不动：元注释/客服话术 4 组、工具残留 markup bugs/占位日期、check-cn-quotes.py、防火墙/对标 ±2 行白名单、KOUYU_PAT/ZIZHENG_PAT 软词表、开篇模板/超长段落/句长方差（本就是 WARN，措辞统一「供 reviewer 参考」）。

约束：下游 cicpa GLOSSARY 锁定词「开箱即用」不得在重组中丢失——核实结果：该词不在脚本与 anchors 任何词表内（仅存在于下游 GLOSSARY 与评测语料正文），零迁移；该结论须记入汇报。

验收方式：`bash -n` 通过；7 个 fixture 退出码与重标后预期一致；`grep fix_word` 无残留；`grep '"auto"'` 无归一分支残留。
